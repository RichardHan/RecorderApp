# 錄音照片時間附件（#40）

實作提案 [#40](https://github.com/RichardHan/RecorderApp/pull/40)。

- 錄音頁「照片」可啟動系統相機或系統照片選擇器。使用按下「拍照／選圖」時的錄音時間，不使用拍攝完成的牆鐘時間；不主動暫停錄音。外部相機是否搶走麥克風仍受裝置／相機 App 影響。
- 相機結果即使在停止錄音後返回，也保留原錄音歸屬；取消的錄音拒絕晚到的結果。開始下一段不會承接上一段照片。
- 每段最多 30 張，說明最多 80 字。匯入時依方向解碼、長邊最多 1600px、重新編碼 JPEG，不保留原照片 EXIF。
- 播放頁可補加、改說明、刪除，點縮圖放大、點時間跳轉。具有真實時間的逐字稿會在最近段落下顯示縮圖；沒有時間／逐字稿時仍可用照片列表。
- Room 14 → 15 自動遷移加入照片與錄音中暫存歸屬。錄音中無 recordingId，儲存音訊後交易綁定；已儲存照片以 recordingId 外鍵 CASCADE 清除。
- 照片位於 `noBackupFilesDir/recording_photos`，不進 Android 圖檔備份、Drive 音訊上傳、AI 請求、文字匯出。系統相機只獲得單張暫存 URI 權限；暫存檔在成功、取消或失敗後刪除。App 不新增相機或相簿讀取權限。
- App 內將錄音移入垃圾桶時照片一併刪除（與現有書籤生命週期一致）；還原音訊不會還原照片。原相簿照片不會被刪除。檔案清除與資料庫操作無法跨媒介交易：啟動與資料變更時會重掃未引用檔案。
- 程序意外終止時已寫入的照片資料仍在；尚未成功儲存的音訊／相機返回不保證可恢復。下一段錄音開始會清除未綁定舊草稿。

## 驗證

本機：照片生命週期、時間歸屬、30 張限制、編碼失敗清除、縮放尺寸與最近段落選擇的單元測試；Debug APK 編譯。

Android 儀器測試：`DBMigrationsTests#migrate_14_to_15_preserves_metadata_and_cascades_photos` 驗證遷移與外鍵；`PhotoStorageTests` 驗證真實 3200×2400 圖片轉 1600×1200 JPEG、檔案與資料庫共同清除、來源圖保留。

`instrumented_tests.yml` 的手動 `test_scope=photos` 只跑這兩項驗收；預設及 PR 觸發仍跑全套。相機硬體、返回畫面與背景錄音需另用實機確認，不以 JVM 或 CI 模擬器測試冒充真機驗證。
