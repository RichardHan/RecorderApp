# 提案：近期回顧（本機彙整最近幾天的錄音重點與未完成待辦）

## 參考依據
- **Fireflies 官方說明（Daily Digest）**：一天結束時把近期所有會議的待辦、決定、待解問題整理在一起，不必逐一打開每段會議。https://guide.fireflies.ai/articles/9187008841-daily-digest-get-a-summary-of-all-your-meetings-in-one-place
- **我們的做法**：沒有使用 Fireflies 的程式或 AI。Fireflies 是用 AI 產生並寄到 email／Slack；我們**只在手機上把已經存在的資料排列出來**，不產生新的 AI 內容、不自動寄送。

## 使用者好處
一週開了很多會時，可以在一個畫面看到最近每段錄音的前幾條重點與還沒勾掉的待辦，點一下進入該錄音；需要時一鍵複製成 Markdown 自己貼到筆記。

## 範圍（最小可行）
1. 錄音列表右上「更多」選單新增「近期回顧」，開啟對話框。
2. 期間可選：今天、最近 7 天（預設）、最近 30 天（依錄音時間）。
3. 每段錄音顯示：標題、日期時間、長度、最新成功摘要的前 3 條重點（沒有摘要就顯示「尚無摘要」）、未完成待辦（最多 5 條，其餘顯示「另有 N 條」）。
4. 點某段錄音＝開啟播放頁。
5. 「複製 Markdown」：把目前的回顧內容複製到剪貼簿（只在本機，不分享、不上傳）。

## 資料、隱私與費用
- 只讀取本機既有的錄音清單、`TranscriptStore` 摘要與待辦（Room，唯讀）。
- 不呼叫任何雲端服務，不產生費用，不新增儲存、不改 Room。

## 邊界情況
- 期間內沒有錄音：顯示「這段期間沒有錄音」。
- 摘要是「目前無重點」：顯示「沒有重點」。
- 錄音數量很多：最多列 50 段，其餘提示「另有 N 段」，避免卡頓；讀取在背景執行緒。
- 讀某段錄音的資料失敗：該段顯示「讀取失敗」，不影響其他段。

## 不在範圍內
- 不用 AI 合併或改寫跨錄音內容、不自動寄送或排程、不做跨錄音問答。

## 驗收測試（單元測試＋人工）
- 期間篩選與排序（新到舊）正確，邊界時間包含在內。
- 重點只取前 3 條並去掉項目符號；「目前無重點」顯示為沒有重點。
- 只列未完成待辦，超過 5 條顯示剩餘數量。
- 超過 50 段時截斷並回報剩餘數量。
- Markdown 輸出格式穩定（標題、日期、重點、待辦 `- [ ]`）。
- 人工：點錄音能開啟播放頁；複製後貼上內容正確。
