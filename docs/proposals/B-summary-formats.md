# 提案 B：可選的摘要格式＋手動重新整理（預設維持精簡）

## 參考依據
- **Notion 官方文件**：
  - 預設是 Auto，可以依會議類型（業務會議、站會、團隊會議）改用不同的摘要指示。
  - 可以自訂格式，也可以設成預設。
  - 改格式只套用到之後的錄音；舊的摘要要按「Retry summary」重新產生。
  - https://www.notion.com/help/ai-meeting-notes （「Change summary instructions」段）
- **我們的做法**：選項名稱與內容由我們自行設計，不照抄 Notion 的範本。

## 使用者好處
需要時可以換成「決議／待辦」等格式，平常仍然是不囉嗦的精簡版。

## 範圍（最小可行）
1. 錄音後摘要的格式選項：
   - **精簡（預設，就是現在的 prompt）**
   - 「決議與待辦」
   - 「條列＋未解問題」
   - 「自訂」
   - 每個格式都必須允許「沒有就省略」，沒有內容時回「目前無重點」。
2. 格式選擇是設定裡的一個欄位，只影響之後新產生的摘要。
3. 「雲端轉錄」對話框的每份摘要加一個按鈕「用其他格式重新整理」：
   - 會先跳出確認視窗，說明會呼叫一次 API、可能計費、會把逐字稿送到哪個服務。
   - 結果**另存成新的 SummaryRecord**（provenance 註明用了哪個格式），舊的摘要不覆蓋。
4. 即時重點（錄音中）不在這次範圍內，仍然使用目前的設定。

## 資料、隱私與費用
- 每按一次重新整理，就是一次付費的 API 呼叫，**一定要使用者手動觸發並確認**。
- 使用者原本自訂的 prompt 不覆蓋、也不遷移；「還原預設」會回到精簡格式。

## 邊界情況
- 自訂格式是空白時，退回精簡格式。
- 逐字稿太短時，回「目前無重點」，不硬湊內容。
- 重新整理失敗時，舊摘要保持不變，並顯示錯誤來自哪個服務。

## 不在範圍內
- 不做共享範本或範本庫。
- 不依會議類型自動切換格式。
- 即時重點不提供格式選擇。

## 驗收測試
- 預設格式的 prompt 跟現在的 `Prompts.summary` 一模一樣（回歸測試）。
- 每個格式的 prompt 都包含「沒有就省略」和「目前無重點」。
- 重新整理會產生新的 id，原本的摘要內容不變。
- 舊的設定資料（沒有格式欄位）讀取時，預設為精簡格式。
- 人工：確認視窗按取消時，不會送出任何網路請求。
