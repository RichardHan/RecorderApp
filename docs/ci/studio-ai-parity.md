# Studio 錄音與 AI 功能對照

舊版基準為 PR #127 合併後的 `5dfc52d57d7c38b28445a791655b0dd4717c72f9`。下表依照舊版播放、錄音、設定與錄音庫畫面的操作，以及雲端轉錄和離線模型說明，列出 Studio 0.3.0 的入口。首次開啟後，可以直接從首頁進入「AI 會議工具」。

| 想做的事 | Studio 入口與使用條件 |
| --- | --- |
| 離線轉錄 | AI 設定選擇及下載 Vosk、SenseVoice、Qwen3-ASR 或 FireRedASR2 AED，錄音詳情可重新辨識。模型依語言、容量與記憶體需求選用。 |
| 本機摘要 | AI 設定下載 Qwen3 摘要模型，再到會議工具選擇錄音及本機摘要。 |
| 雲端辨識或重轉 | AI 設定選取 OpenRouter 或自訂 HTTPS 端點。支援 multipart 語音、相容聊天音訊與 Gemini 原生。分段音訊支援 MP3、並行、選擇性靜音略過、同服務重試、斷點續傳及過濾區段時間提示。 |
| 錄音後自動處理 | AI 設定開啟自動轉錄，選擇 Wi-Fi、遮蔽、摘要、從摘要命名及完成通知。自訂標題會保留。 |
| 錄音中看字幕與會議重點 | 錄音前開啟錄音中 AI 控制（16 kHz WAV）。可於錄音中分別開關本機與雲端字幕，設定區段、重疊、修正、首則重點時間及提示詞。雲端開關只涵蓋同意後的音訊。 |
| 即時分享或會後整理 | Slack 設定選擇開場、重點與最終整理，並在錄音時確認。另可在錄音詳情手動分享。 |
| 管理逐字稿 | 錄音詳情可搜尋、查看逐段時間、定位播放、更正文字、比較兩個版本，也可選歷史逐字稿另存摘要。可匯入逐字稿及匯出字幕。 |
| 分辨說話者與分析語音 | 錄音詳情可在裝置辨識說話者、命名、篩選或匯出。逐字稿工具提供關鍵詞、贅詞與語速。可用時間依來源而定。 |
| 多格式摘要與標題 | AI 會議工具選擇摘要格式、自訂提示詞及是否帶入議程。標題可直接取自已存摘要，或確認後用文字模型建議。 |
| 雙語對照與潤稿 | AI 會議工具逐段並列原文與譯文。不同目標語言可各自保存，潤稿另存；缺段的回應會保留先前成功版本。 |
| 章節與決議 | 會議工具可擷取章節與決議、編輯或刪除條目，亦可手動新增決議。帶有效時間的來源可以點回錄音。 |
| 待辦與後續草稿 | 選擇 AI 建議、從重點加入或手動輸入；可勾選完成並複製未完成項目。利用摘要與已選待辦擬稿後，可編輯、儲存、分享或刪除。 |
| 大綱 | 從已存摘要顯示本機大綱，可複製、請模型整理，再還原本機版本。 |
| 錄音問答 | 選一段錄音提問，可查看來源、保留對話、刪除問答或清除紀錄。錄音庫與搜尋結果支援選取多段逐字稿提問。 |
| 回顧與匯出 | 錄音庫可依近七天、三十天回顧，選取錄音匯出逐字稿、摘要等文字結果 ZIP。單一會議結果另可匯出 Markdown。 |
| 服務設定與費用 | 語音和文字模型可用不同主機與憑證。設定可測試連線、遮蔽識別資料、設定模型單價。錄音收據與用量畫面區別服務回報費用和本機估算。 |

## GitHub 驗證範圍

- 單元測試涵蓋搜尋、下載續傳及校驗、說話者時間對齊、雙語分段、費用與字幕匯出。
- API 36 儀器測試使用固定測試音訊、可離線辨識的英文模型，以及 runner 內的模擬服務。檢查實際 HTTP 請求、憑證目的地、MP3 音訊、重試、逐段編輯與儲存結果。
- GitHub 的 APK 操作測試從首頁進入會議工具，讀取雙語逐字稿、新增待辦和手動決議，再重開 App 檢查保存結果。截圖與測試報告由同一次工作流程上傳。
- 大型模型在個別手機的效能、付費服務的回答品質、實際 Slack 頻道與 Drive 帳戶，須在相應裝置與帳戶才能驗證。
